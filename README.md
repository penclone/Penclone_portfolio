# Penclone Portfolio Site

AI voice agent & automation portfolio, built as a static site with React (pre-compiled, no runtime JSX transform) and Tailwind CSS (compiled, no CDN warning).

## Deploying to GitHub Pages

1. Push this folder to a new GitHub repo.
2. In the repo, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push to `main` (or run the workflow manually from the **Actions** tab). The included workflow (`.github/workflows/deploy.yml`) will:
   - install dependencies
   - compile Tailwind CSS from `src/input.css` into `dist/tailwind.css`
   - deploy `index.html` + `dist/` to Pages
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

No server, no database — it's a fully static site, exactly as requested.

## Making content edits later

- **Copy, sections, links, pricing:** edit the data objects near the top of `src/app.jsx` (e.g. `SERVICES`, `TESTIMONIALS`, `PRICING`, `CASES`, `CALENDAR_URL`, `WHATSAPP_URL`).
- **After editing `src/app.jsx`**, you need to recompile it to `dist/app.js` before pushing (the GitHub Action only rebuilds the CSS, not the JS bundle). Easiest way: send the updated `src/app.jsx` back to Claude and ask for a recompiled `dist/app.js` — or compile it yourself with:
  ```
  npx tsc --jsx react --target es2019 --module none --outFile dist/app.js --allowJs src/app.jsx
  ```
- **Styling/colors/fonts:** edit the `<style>` block directly in `index.html`.

## Local preview

Since `dist/tailwind.css` is only generated by the GitHub Action (or by running `npm install && npm run build:css` locally), opening `index.html` directly before that step will look unstyled. Run:
```
npm install
npm run build:css
```
then open `index.html` in a browser to preview locally.
